# Divine India visual system

## Brand idea
A contemporary spiritual travel and culture platform rooted in Hindu heritage. The visual language should feel warm, serene, authentic and premium—not like a crowded festival poster.

## Core palette

| Token | Hex | Use |
|---|---|---|
| Saffron | `#E87922` | Primary actions, highlights |
| Deep maroon | `#5A1827` | Brand depth, emphasis |
| Temple gold | `#C99A3B` | Decorative accents, premium details |
| Warm ivory | `#FFF8ED` | Main background |
| Sand | `#F3E7D5` | Soft surfaces |
| Ink | `#2B211B` | Body text |
| Muted brown | `#7C6A5B` | Secondary copy |

## UI principles
- Use generous whitespace, rounded cards and clear hierarchy.
- Use saffron for primary actions and maroon for strong brand anchors.
- Use temple gold sparingly; avoid gold text on cream when contrast is low.
- Use devotional motifs as subtle ornament, not as background noise.
- Keep body text readable and controls at least 48 logical pixels high.
- Use real, permissioned imagery for temples, ghats, festivals and destinations in production.
- Keep banner content remotely managed through the Admin app.

## Image guidance
Homepage banners should be landscape images with a 16:9 or 2:1 crop, a safe text area, concise headline and one clear call to action. Admin should preview the selected image before publishing.
